# Samples-Display

https://mattchrisp.github.io/Samples-Display/ — one folder per page, each with its own `audio/`.

- `audiointeraction/` — AudioInteraction-3B release vs Hokkien tunes. Generated by
  `Myna-Interaction/audiointeraction-hokkien/scripts/export_samples_display.py` and `export_quick_display.py`
  with `--site <this repo>/audiointeraction`.
- `linear-bridge/` — Linear Bridge v1 sample outputs.
- `emotion-gallery/audio/` — older RAVDESS-conditioned emotion set (audio only, not linked).

`styles.css` at the root is shared. `audiointeraction.html` redirects to the old URL's new home.
