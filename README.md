# Samples-Display

https://mattchrisp.github.io/Samples-Display/ — one folder per page, each with its own `audio/`.

- `audiointeraction/` — AudioInteraction-3B release vs Hokkien tunes. Generated by
  `Myna-Interaction/audiointeraction-hokkien/scripts/export_samples_display.py` and `export_quick_display.py`
  with `--site <this repo>/audiointeraction`.
- `hokkien-tts-dict/` — dict check: Gemini 3.5 Flash-Lite Hokkien Hanji from Mandarin (code-switch rule), with no dictionary,
  the SG Hokkien dictionary with meanings, and only its checked words with meanings; Traditional and Simplified TTS clips.
  Run by `scripts/dict_cs_check.py`; page by
  `Myna-Interaction/audiointeraction-hokkien/scripts/export_dict_check_display.py --site <this repo>/hokkien-tts-dict`.
  (Until 2026-11-20 it showed the English-input run, two models x five arms.)
- `hokkien-drama-check/` — drama check: real WWBWB drama clip next to each model × arm TTS clip (Simplified), shuffled,
  with a "best" pick per line kept in the browser. Generated by
  `Myna-Interaction/audiointeraction-hokkien/scripts/export_drama_check_display.py --site <this repo>/hokkien-drama-check`.
- `linear-bridge/` — Linear Bridge v1 sample outputs.
- `emotion-gallery/audio/` — older RAVDESS-conditioned emotion set (audio only, not linked).

`styles.css` at the root is shared. `audiointeraction.html` redirects to the old URL's new home.
