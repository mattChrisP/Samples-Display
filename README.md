# Samples-Display

Linear Bridge (codec align, fixed v1) sample outputs — identity baseline vs.
native-text ceiling vs. the trained bridge, for the same Hokkien s2s answers.

[Open the sample gallery](https://mattchrisp.github.io/Samples-Display/)

Older sample sets (e.g. the RAVDESS-conditioned emotion set) are still under
`audio/` but are no longer linked from the page — swap `index.html`/`app.js`/
`samples.js` back to display them again if needed.

[AudioInteraction timing test](https://mattchrisp.github.io/Samples-Display/audiointeraction.html):
when the released AudioInteraction-3B answers, with the same audio under different
pauses (digital silence, room noise, noise under the speech, their web demo).
Generated by `Myna-Interaction/audiointeraction-hokkien/scripts/export_samples_display.py`.
